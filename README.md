# TeamBattle

**ジャンル：** 2Dバトル  
**対応機種：** PC  
**プレイ人数：** 1～5人  

---

## 基本操作方法
※2人以上でプレイする場合はコントローラー必須

| キーボード | コントローラー | 動作 |
|------------|----------------|------|
| W / ↑      | 十字キー上     | 上   |
| S / ↓      | 十字キー下     | 下   |
| A / ←      | 十字キー左     | 左   |
| D / →      | 十字キー右     | 右   |
| Enter      | Aボタン        | 動作 / 決定 |
| BackSpace  | Bボタン        | 戻る |
| L          | Lボタン        | Lで動作する物 |
| R          | Rボタン        | Rで動作する物 |
| エスケープ | なし           | 終了 |

---

### 備考
- タイトル画面で **Bボタン** を押すと終了
